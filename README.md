# Perfect Player · 完美球员

纯网页篮球生涯模拟：创造自己的球员，打完常规赛、季后赛，一路经历训练、事件和文字直播。

这是静态网页，打开就能玩，不需要安装。

## 在线玩

在线玩：<https://dhsa33.github.io/perfect-player/>

## 本地运行

```bash
python -m http.server 8035
```

然后打开 <http://127.0.0.1:8035/>。

## 后续开发计划

下面是灵感备忘，不是排期承诺。实现时仍以球员第一人称、现有生涯循环为准，不必一次做完。

### 薪资、选秀与人事

- **球员 / 球队薪资**：合同、薪资帽、球队账本，让续约、顶薪、角色球员合同有差别
- **选秀**：新秀年、选秀顺位、落选或低顺位逆袭都可以做成生涯入口
- **工资代币**：球员工资所得走另一套代币，和现有人气 / 局内资源分开，用来消费、投资或影响场外选择
- **球员视角的球队影响力**：不能变成 GM 模拟，但人气、更衣室地位够高时，可在一定程度影响战术侧重、轮换、交易意愿

### 叙事与人物

- **更丰富的事件系统**：同场事件仍不能互相打脸；常规赛关键战保持克制，事件重量放在故事、关系、赛季节点上
- **感情线加分支**：多条线、多个女主，各有对应配图，选择会留下后果而不是同一套对话换皮
- **中国篮球线**：可拆成多条分支。未来选秀可能出现其他中国球员；彼此既是联盟对手，也可能是国家队队友——集训、世预赛、奥运会窗口都是可写的冲突和羁绊

### 还想做、但先记着

交易谈判的拉扯、国家队窗口和 NBA 赛季的交错、媒体与舆论对合同和感情的反噬、更衣室派系、退役后的第二条人生……想到就往这里补。做的时候先问「从球员座位上看，这件事值不值得打断一场比赛」。
