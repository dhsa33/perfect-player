# Perfect Player · 完美球员

纯网页篮球生涯模拟。创造自己的球员，从选秀走进常规赛和季后赛，把训练、事件、舆论和一场场球打成一条完整生涯。

打开就能玩，不用安装。

**[在线玩](https://dhsa33.github.io/perfect-player/)**

本地预览：

```bash
python -m http.server 8035
```

然后打开 <http://127.0.0.1:8035/>。改过页面或脚本后请硬刷新（Ctrl+F5）。

## 生涯怎么走

先取名字、选头像，再拼出这名球员的身体和技能。选秀前后会碰到试训、采访、体测和行情波动，顺位不是开场一句旁白，而是这段准备的结果。

进入联盟之后，大部分常规赛会快速打完。揭幕战、收官战、死敌、排名相关的关键战，以及季后赛，会停下来让你选择「观看」或「跳过」。附加赛按场进行，没有整季跳过。常规赛可以整季快进，季后赛可以跳过当前系列。

观看和跳过用同一套攻防，不会打出两场不一样的比赛。伤病、禁赛、训练和赛季事件都挂在这条时间线上，不当总经理模拟器。

## 系统

### 观看直播

关键场次选择观看后，比赛按回合往下走：比分、时钟、文字播报同步更新。播报会写清谁持球、谁对位、有没有协防、球落在哪个区位，过程跟结果对得上，不会各说各话。

加快和「看完本场」会收起动画，只保留结果。

### 俯瞰球场

普通速度观看时，比分板下有一块按 NBA 球场比例画的俯瞰图。十个人都会跑，不只动持球那两个人；球有自己的路线，传球和投篮会飞，不会贴在人身上瞬移。

投失、篮板、抢断这类活球，会从上一次站位接着跑。命中、犯规、出界、节间等死球才会重新落位。画面和那句播报共用同一回合数据。

### 球风技能

生涯里会获得球风点，用来点出投射、终结、组织、防守等风格。技能看你的属性门槛，部分流派互相排斥，点出来的是打球方式，不是一张无冲突的加成表。

### 球员状态

人气、争议、媒体信任、球队默契、教练与更衣室关系、中国人气等会写进状态条。它们慢慢影响比赛、舆论和去留，而不是每场刷新一套人格。

局内事件主要改这一回合的攻防；人气、争议、媒体和默契不会被单场选择推得太猛。

### 赛季事件

赛季中会插入独立事件：临场判罚、身体管理、更衣室、媒体、商务。每件事有自己的场景和选择，不是同一套对话换皮。效果会落到状态、关系和接下来的比赛里。

### 生涯剧情

跨赛季的故事线会认人、认队：

- **宿敌**：对位里被点名，采访被拱火，再在全国转播里见面
- **名宿**：按位置遇到对应的历史人物，也可能碰到本队退役球衣那一线
- **中国线**：家乡、国家队窗口、征召和队内角色
- **更衣室**：新秀、老将、忠诚和领导力相关的选择

人物从当场双方名单里来，不会出现对阵里没有的人。

### 荣誉评选

赛季结束按媒体投票的思路发奖，而不是按一项数据直接排序。覆盖 MVP、最佳防守球员、最佳新秀、进步奖、最佳第六人、最佳阵容、最佳防守阵容、最佳新秀阵容和全明星。出场、影响力和位置都会进入讨论，冷门和争议结果是设计的一部分。

### 成就与传承

生涯里的节点会解锁成就。已经解开的成就跨存档保留；需要在同一条生涯里累计的成就，不会把多个新档加在一起。

传承祭坛用生涯积累强化下一世，属于新开档时的底子，不改当前这场球的胜负判定。

## 以后想做

灵感备忘，不是排期。一律从球员第一人称接入现有生涯，不当总经理模拟器。

常规赛关键战保持克制；同场事件不能互相打脸；能影响球队，但不能直接操作球队账本和交易桌。

**经济**  
球队账本（薪资帽、合同、奢侈税）和球员钱包（工资到账后的个人代币）分开。合同档位让「值不值得给你顶薪」能被感觉到；花钱、投资、破产走钱包，不靠人气冒充有钱。

**人事**  
选秀是生涯入口，之后每年仍有新秀进联盟。合同与去留看表现、伤病和球队空间。交易里球员可以表态、施压，不能自己撮合方案。更衣室地位够高时，只能有限度影响侧重，改不了教练体系。

**叙事**  
继续扩事件引擎，把合同、交易、国家队窗口尽量做成事件，而不是另开经营表。感情线是人物线，中国篮球线是身份线，两条并列，不互相当子情节。
