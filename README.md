# Perfect Player · 完美球员

纯网页篮球生涯模拟：创造自己的球员，打完常规赛、季后赛，一路经历训练、事件和文字直播。

这是静态网页，打开就能玩，不需要安装。

## 在线玩

在线玩：<https://dhsa33.github.io/perfect-player/>

## 本地运行

```bash
python -m http.server 8035
```

然后打开 <http://127.0.0.1:8035/>。

## 说明

- 非官方粉丝向作品，队名、队徽与球员形象归 NBA / 各球队所有
- 存档在浏览器本地，换设备或清缓存会丢
- 虎扑活动 SDK 在 GitHub Pages 上不可用，游戏本身走本地逻辑
