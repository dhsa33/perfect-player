# Perfect Player · 完美球员

纯网页篮球生涯模拟游戏。创建自己的球员，从选秀走进常规赛和季后赛，把训练、事件、舆论和一场场球，打成一条完整生涯。

打开浏览器就能玩，不用安装。

**[在线玩](https://dhsa33.github.io/perfect-player/)**

---

## 本地运行

```bash
python -m http.server 8035
```

打开 <http://127.0.0.1:8035/> 即可。改过文件后硬刷新（Ctrl+F5）。

## 游戏内容

### 生涯模式

- **选秀与建队**：自定义球员属性、位置、体型，通过选秀进入 NBA
- **赛季推进**：82 场常规赛 + 季后赛，支持快速模拟和关键场观看
- **实时文字直播**：关键比赛可逐回合观看，俯瞰视角感受攻防节奏
- **训练与成长**：每赛季选择训练方向，属性随年龄自然成长与衰退
- **休赛期事件**：自由市场、续约谈判、训练营选择，影响下赛季状态
- **荣誉系统**：MVP、最佳阵容、总冠军等赛季荣誉，生涯成就解锁

### 纪元模式

选择 1984 / 1996 / 2003 三个历史时代之一开局，体验不同时期的 NBA 格局：

- 球队名单按时代真实还原， expansion / relocation 自动跟进
- 历史球星按真实出生年计算年龄，成长与衰退曲线贴合现实
- 当季新秀走独立成长曲线，不会一进联盟就是巅峰

### 局内模拟

关键场可选择「观看本场」，进入逐回合文字模拟：

- 球员根据属性与体力自主决策攻防
- 比赛节奏、犯规、暂停、加时均真实模拟
- 实验室模式可独立调试特定对局
