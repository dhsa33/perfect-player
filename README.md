# Perfect Player · 完美球员

纯网页篮球生涯模拟：创造自己的球员，打完常规赛、季后赛，一路经历训练、事件和文字直播。

这是静态网页，打开就能玩，不需要安装。

## 在线玩

在线玩：<https://dhsa33.github.io/perfect-player/>

## 本地运行

```bash
python -m http.server 8035
```

然后打开 <http://127.0.0.1:8035/>。

## 后续开发计划

灵感备忘，不是排期。一律从球员第一人称接入现有生涯循环，不当总经理模拟器。

共同边界：常规赛关键战保持克制；同场事件不能互相打脸；能影响球队，但不能直接操作球队账本和交易桌。

### 1. 经济（两套账，互不混用）

| | 球队账本 | 球员钱包 |
| --- | --- | --- |
| 记什么 | 薪资帽、合同、奢侈税、顶薪 / 角色合同 | 球员工资到账后的个人代币 |
| 用来干什么 | 续约空间、能不能留人、球队愿不愿意交易 | 消费、投资、场外选择 |
| 不和谁混 | 不进球员钱包 | 不和人气、局内资源、球队薪资混用 |

- 球队侧先做出合同档位和帽压力，让「值不值得给你顶薪」能被玩家感觉到
- 球员侧工资是另一套代币，发薪、花钱、破产都走这条，不靠人气冒充有钱

### 2. 联盟人事（球员可施压，拍板权仍在球队）

按生涯时间线，不要揉成一个「经营系统」：

1. **选秀**：生涯入口（高顺位 / 低顺位 / 落选），以及之后每年进入联盟的新秀
2. **合同与去留**：新秀合同、续约、提前续约、走出合同年；结果受表现、伤病、球队空间影响
3. **交易**：球员可以表态、传话、用地位施压，不能自己撮合方案；被交易是事件，不是 GM 面板
4. **战术与轮换**：更衣室地位够高时，可有限度影响侧重（攻防风格、球权、上场时间），改不了教练体系本身

选秀产出的新秀，会接到下面的中国篮球线和更衣室关系，不在这里写故事。

### 3. 叙事（引擎和两条主线分开）

**3.1 事件引擎（容器）**

扩容日常、赛季节点、媒体、更衣室冲突。重量放在故事和关系上，不靠把更多比赛标成关键战。新系统（合同、交易、国家队窗口）应尽量做成事件，而不是另开一张经营表。

**3.2 感情线（人物线）**

- 多女主、多分支，选择有后果，不是同一套对话换皮
- 每个女主有对应配图
- 可与合同年、舆论、国家队征召交叉，但不并进中国篮球线

**3.3 中国篮球线（身份线）**

和感情线并列，不要写成感情线的子情节：

- 国家队窗口：集训、世预赛、世界杯 / 奥运会，和 NBA 赛季交错
- 其他中国球员：之后选秀可能出现；联盟里是对手或队友，国家队里是队友
- 多分支：征召与否、队内竞争、媒体国籍叙事、伤病与让路

### 4. 未归类（想到再归到上面）

| 点子 | 倾向归入 |
| --- | --- |
| 交易谈判的拉扯、被交易当天 | 2. 人事 · 交易 |
| 更衣室派系 | 2. 人事 · 战术，或 3.1 事件 |
| 媒体 / 舆论反噬合同和感情 | 3.1 事件，钩到 1 和 3.2 |
| 退役后第二条人生 | 暂不归类，另开生涯阶段时再说 |

做之前先问：从球员座位上看，这件事值不值得打断一场比赛。新灵感按「经济 / 人事 / 事件引擎 / 感情 / 中国篮球」五类补，避免再写成一锅粥。
